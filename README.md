# 🛡️ PrivacyGuard AI

**PrivacyGuard AI** არის ჭკვიანი ასისტენტი, რომელიც გეხმარებათ რთული და გრძელი "მოხმარების პირობების" (Terms and Conditions) სწრაფ ანალიზში.

## ✨ ფუნქციები
* 🔗 **ავტომატური სკრეიპინგი:** ჩასვით საიტის ლინკი და პროგრამა თავად წაიკითხავს ტექსტს (Selenium-ის დახმარებით).
* 🤖 **AI ანალიზი:** Gemini AI მომენტალურად პოულობს "წითელ დროშებს" (Red Flags).
* 📊 **უსაფრთხოების ქულა:** საიტის პრივატულობის შეფასება 1-დან 10-მდე.
